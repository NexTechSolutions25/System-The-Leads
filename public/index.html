Conectar o ambiente

  1. Copie .env.example para .env.
  2. Configure REDIS_URL e execute npm run worker.
  3. Para captação real, configure GOOGLE_PLACES_API_KEY com Places API (New) e faturamento habilitados.
  4. O uso dos dados do Google em CRM depende de direitos de armazenamento expressamente autorizados. Consulte o README antes de ativar.
  5. Cadastre em WEBSITE_ALLOWED_HOSTS os domínios cujos termos permitem análise. O analisador também verifica robots.txt.

As chaves ficam no servidor. Nenhuma mensagem é enviada automaticamente.

Privacidade e dados

Use somente contatos comerciais públicos ou autorizados. A exclusão remove o registro, análises e evidências. São preservados hashes de bloqueio para evitar recaptura; isso é pseudonimização, não anonimização irreversível. Dados de demonstração nunca habilitam contato.
